# 🎲 BINGO PREMIUM - Violet/Cyan - Modelo Anterior Restaurado

Sistema completo de Bingo Premium com modelo violet/cyan, detecção automática de ganhadoras e modo tanto faz lado!

## ✨ Funcionalidades - 134 Testes 100%

### 🎨 Modelo Premium
- Fundo #050507 com blur violet 900px + cyan 700px
- Glass strong com backdrop-blur 20-28px
- Fonte Outfit + JetBrains Mono
- Gradiente violet → cyan

### 🏆 Modo Bingo - Tanto Faz Lado
- **BINGO 5 NÚMEROS**: Vale horizontal ➡️, vertical ⬇️ e diagonal ↘️↙️ - tanto faz o lado!
- **CARTELA CHEIA**: 24 números + FREE = 25 marcações
- Escolha 1 ou 2 modos na ⚙️ CONFIG
- 12 linhas verificadas (5H+5V+2D)

### 🎮 Sistema Completo
- Globo principal 360px - 22 bolas com física
- Projetor TV 460px - 32 bolas - tamanho correto
- Grade 52px com letra + número B1-O75
- Bola saída 140px + projetor 160-180px
- Voz pt-BR fala Letra + Número: "Letra B, número 7. B, 7"
- Tipo voz feminina/masculina + seleção nome
- Repetição 1X/2X/3X + velocidade 0.3-1.2
- PNG HD 800x900 + PDF 6 por folha A4
- Detecção automática de ganhadoras em todas cartelas
- Salva tudo no localStorage

## 🚀 Como usar

1. Abra `index.html` no navegador
2. Gere cartelas: digite quantidade → GERAR
3. Clique 📄 PDF para imprimir 6 por folha A4
4. Configure modo bingo em ⚙️ CONFIG
5. Clique ▶ GIRAR GLOBO QUÂNTICO
6. Para projetar na TV: 📺 TV • 460PX
